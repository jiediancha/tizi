## 梯子是什么：机场、VPN、自建三种梯子的区别

梯子是能访问境外网站的工具的统称，常见三种：机场、成品 VPN、自建服务器。它们差在两件事：线路归谁管，你要自己配多少东西。

| 类型 | 你拿到的是 | 你自己要做的 | 出问题时 |
| --- | --- | --- | --- |
| 机场 | 一条订阅链接 | 装客户端、导入订阅 | 换节点，或者看机场公告 |
| 成品 VPN | 一个装好就能连的 App | 几乎不用配 | 只能等它修，外面看不到原因 |
| 自建 | 一台境外服务器 | 装服务端、配协议、维护 IP | 全靠你自己 |

大多数人该从机场开始。

理由很简单：机场按月卖，节点多，一个节点坏了换下一个；它有官网、有公告、有订阅地址，这些都是从外面能核查的东西。成品 VPN 省事，代价是你看不见它背后是什么线路，连不上的时候分不清是它坏了还是被封了。自建适合会用 Linux、愿意自己换 IP 的人，图的是独享，不是省钱。

「翻墙梯子」「科学上网工具」说的是同一类东西。下文说「梯子」，默认指机场。三个说法的边界，网页版另有一页：[梯子、机场、VPN 分别指什么](https://www.jiediancha.com/tizi/)。

## 梯子推荐：挑梯子我只看四件事

挑梯子不看宣传页的速度截图。我只看四件事：订阅格式你的客户端能不能用，晚高峰稳不稳，客服多久回，能不能先买一个月。

**订阅格式。** 你用 Clash 系客户端，就要它给 Clash 订阅；用 v2rayN，就要通用订阅。只给自家 App、不给订阅链接的，我直接跳过——换客户端它就跟着作废。

**晚高峰。** 白天谁都快。好用的梯子不是测速最高的那个，是晚上九点打开视频不用换节点的那个。别人的测速截图搬不到你家宽带上，原因见[机场测速为什么要自己测](https://www.jiediancha.com/speedtest/)。

**客服。** 下单前先问一个技术问题，看多久回。跑路之前，客服往往最先消失。

**能不能月付。** 年付便宜，但你在为一家还没验证过的服务商预付一年。

验证方法我只用一种：买一个月，连续三天晚上九点左右测同一个节点，取最差的那次当它的真实成绩。三天都能正常看 1080p，再考虑长期套餐。这一个月里还该顺手验证什么，见[机场试用该验证的四项](https://www.jiediancha.com/trial/)。

## 机场是什么：第一次买机场该怎么下单

机场是按月或按流量出售代理节点订阅的服务商。你付钱拿到一条订阅链接，把它导入客户端，客户端里就有了一组可以切换的节点。

「机场」这个叫法，常见的说法是来自早期 Shadowsocks 客户端的纸飞机图标：节点被叫作「飞机」，卖节点的就成了「机场」。你只需要知道它卖的是三样东西：节点（线路）、订阅（把节点打包给你的链接）、流量（每月能用多少 GB）。

第一次下单，我会按这个顺序走：

1. **先定客户端，再挑机场。** 手机用什么、电脑用什么，先想好（见「翻墙软件怎么选」一节）。然后只看提供你那个客户端能用的订阅格式的机场。
2. **只买月付最低档。** 第一个月的目的是验证，不是省钱。
3. **下单前问客服一个问题。** 比如「你们的订阅支持 Clash 吗」。回得快、回得准，加分；一天没人回，换一家。
4. **付款后马上导入、马上用。** 别等到要用的时候才发现订阅导不进去。
5. **记下到期日。** 到期后订阅会失效，症状和「被封了」一模一样，很多人在这上面白折腾一晚上。

套餐页上的这几个字段比价格更要紧，它们通常写在小字里：

| 字段 | 为什么要看 |
| --- | --- |
| 流量倍率 | 有的节点按 2 倍、3 倍扣流量。100GB 的套餐在高倍率节点上实际只能用三四十 GB |
| 设备数 | 低档套餐常限 2–3 台。手机、电脑、平板一起挂很容易超 |
| 限速 | 有的低价档限了带宽上限，看 4K 会卡 |
| 重置日 | 流量按自然月重置还是按购买日重置，月底用完会差好几天 |
| 是否支持月付 | 只卖年付的，我不买 |

## 性价比机场：每 GB 单价和倍率怎么算

性价比机场先看它还在不在，再算每 GB 单价。单价等于月付价除以流量，倍率、限速、设备数都会让它失真。

算法本身一行就够：**月付价格 ÷ 该档流量 = 每 GB 单价**。¥20 买 120GB，每 GB 约 ¥0.17。

难的是这个数什么时候骗人：

**倍率。** 你常用的节点是 1.5 倍率，那 120GB 实际是 80GB，单价从 ¥0.17 变成 ¥0.25。比价之前，先看你会用的那几个节点标的倍率。

**用不完。** 你每月只用 40GB，买 200GB 的档位单价再低也是浪费。按自己的用量选档，再比单价。

**年付折算。** 年付摊到每月通常便宜一截。但你在用这一截折扣换「钱锁一年」的风险。这个行业里服务商更替很快，一年里出事的概率不低，折扣通常补不回这个风险。

便宜机场的低价一般靠三种结构撑着，能看懂是哪一种，就知道它的价能不能信：

- **规模摊薄**：用户多，单位成本自然低。这种一般也卖月付，因为它不靠预付回笼钱。能买。
- **线路降配**：用普通中转代替专线，成本差一个数量级。不算坑，但别指望它晚高峰和专线一样。
- **预付回笼**：靠大幅年付折扣提前收现金。折扣越狠，风险越集中在你这边。我不碰。

价格低到连带宽成本都不够的，要么超售，要么准备跑。月付个位数的，我默认是后者，除非它能证明不是。

上面那张推荐表里的「折合每 GB」一列就是按这个方法算的，核对日期同表。

## 翻墙打不开先分层：被封、限流、到期还是跑路

翻墙打不开时先分清是哪一层坏了：本地网络、订阅、节点线路，还是机场本身。不同层的修法相反，查错层只会越修越乱。

最常见的误判是把「打不开」直接当成「跑路了」。入口打不开的原因至少有这几种，只有末尾那一种和停运有关：

- 网络层封锁：域名或 IP 在你的网络里被阻断
- 访问限制：对方对你的出口 IP 做了拦截
- 证书或配置问题：TLS 握手失败、证书过期
- 基础设施故障：机房、CDN、DNS 服务商临时出事
- 域名到期没续、在赎回期或在转移
- 真的停止运营

所以网页版记录机场入口状态时分五档，不可达和停运严格分开（当前分布见[服务商状态总览](https://www.jiediancha.com/status/)，按状态分组见[按可用性状态分组查看](https://www.jiediancha.com/topic/)，眼下能打开的见[当前可达的服务商清单](https://www.jiediancha.com/topic/up/)）：

| 状态 | 意思 |
| --- | --- |
| 可达 | 最近一次探测能正常打开它的入口 |
| 暂时不可达 | 最近探测失败，但还在观察期。被墙、限流、临时故障都在这一档，不代表停运 |
| 长期不可达 | 连续多次失败、超出观察期。仍然没确认停运 |
| 已确认停运 | 有可核对的公开依据（官方公告、公开存档）表明停止运营 |
| 待核实 | 还没探测，或数据不够判断。不猜 |

两条改判规矩：单次探测失败不改判，只进观察期；要改成「已确认停运」必须拿得出公开依据，失败再久也只能到「长期不可达」。

这套口径你自己排查时也能用。你的梯子突然不能用，按这个顺序问：

1. 关掉代理，本地能正常上网吗？不能，问题在你这边。
2. 套餐到期了吗？流量用完了吗？去后台看。
3. 订阅能更新吗？更新报错，是订阅层；更新成功但节点全不通，是线路层。
4. 机场官网打得开吗？打不开也别急着下结论，可能只是官网域名被墙。看它的公告渠道。

完整的判定规则在[不可达与停运怎么区分](https://www.jiediancha.com/method/)。

## 科学上网入门：客户端、订阅、规则三件事

科学上网需要三样东西配合：客户端负责连接，订阅负责提供节点，规则负责决定哪些网站走代理。三样里坏一样都会表现成「上不去」。

**客户端**是你装在设备上的软件，它本身不带任何节点，是个壳。下一节按设备列了常用的几个。

**订阅**是机场给你的一条链接，客户端用它拉取节点列表。同一家机场通常给好几种订阅，名称大致是「Clash 订阅」「通用订阅 / V2Ray 订阅 / Base64 订阅」「sing-box 订阅」。拿错类型是导入失败的头号原因：Clash 订阅导进 v2rayN，列表是空的。三种订阅失效各自的表现，见[订阅拉不到节点和节点全不通的区别](https://www.jiediancha.com/subscription/)。

**规则**决定流量怎么走。常见三种模式：

| 模式 | 效果 | 什么时候用 |
| --- | --- | --- |
| 规则 / 分流 | 国内网站直连，境外网站走代理 | 日常一直开着这个 |
| 全局 | 所有流量都走代理 | 排查问题时临时切过去 |
| 直连 | 所有流量都不走代理 | 等于关掉 |

一个排查技巧：网页打不开时切到全局模式试一次。全局能开、规则模式不能开，是规则把那个域名分到了直连；全局也打不开，问题在节点或订阅，和规则无关。

订阅链接别发给别人。多人同时用一条订阅会触发机场的异常检测，轻则限速，重则封号，症状和「被墙了」一样。

三条硬规矩：

- **只从官方发布页下载。** 第三方下载站的安装包被二次打包的情况很常见。代理客户端被动了手脚，等于把你的全部流量交出去。
- **v2rayN 和 v2rayNG 是两个软件。** 名字差一个字母，一个是电脑版，一个是安卓版，界面完全不同，教程不能混看。详见[v2rayN、v2rayNG 和 Xray 的区别](https://www.jiediancha.com/blog/v2rayn-vs-v2rayng-vs-xray/)。
- **杀毒软件常把代理内核当风险程序删掉。** 表现是「昨天还能用，今天一启动就报错」。把整个客户端目录加进白名单，只加单个 exe 没用，内核更新会换文件名。

表外还有不少客户端，比如 iOS 上的 Stash、Loon、Surge，多平台的 Hiddify、Karing。下载前想确认它们的发布页现在能不能打开、近期有没有换过地址，网页版有逐个记录：[Stash 发布页可用性](https://www.jiediancha.com/status/stash/) · [Loon 入口变更记录](https://www.jiediancha.com/status/loon/) · [Surge 现在能打开吗](https://www.jiediancha.com/status/surge/) · [Hiddify 入口状态](https://www.jiediancha.com/status/hiddify/) · [Karing 可用性记录](https://www.jiediancha.com/status/karing/) · [sing-box 项目页状态](https://www.jiediancha.com/status/sing-box/)。汇总见[工具与客户端清单](https://www.jiediancha.com/topic/tool/)。

菜单名和按钮位置每个大版本都在变，下文的步骤只说做什么，具体名称以你装的那一版为准。

## Clash 机场：订阅导入和常见报错

Clash 机场就是给 Clash 订阅链接的机场。导入分三步：复制订阅、粘进客户端、选节点并开系统代理。报错多半是没开系统代理。

**导入步骤**

1. 在机场后台复制 **Clash 订阅**（完整的 `https://` 开头那一串，别漏结尾参数）。
2. 打开客户端，进订阅或配置管理，新建一条，粘贴链接，保存。
3. 更新订阅，节点列表出现，说明导入成功。
4. 选一个节点，**打开系统代理**。只选节点不开系统代理，等于什么都没变。

第一次导入要在网络能通的时候做。很多机场的订阅地址本身在境外，没有可用代理时更新不了订阅——这也是换电脑以后全部失效的常见原因。

**常见报错，按现象查**

| 现象 | 最可能的原因 | 先做什么 |
| --- | --- | --- |
| 导入后列表是空的 | 拿错订阅类型 | 确认复制的是 Clash 订阅 |
| 订阅更新失败 | 订阅地址访问不到，或链接已过期 | 浏览器直接打开链接，看能不能返回内容；到后台看套餐是否到期 |
| 有节点、选了，网页还是打不开 | 系统代理没开 | 打开系统代理 |
| 系统代理开了还是打不开 | 规则把该域名分到了直连，或 DNS 出问题 | 临时切全局模式试 |
| 节点全部超时 | 套餐到期、流量用完、本地网络出问题 | 先关代理看本地能不能上网，再去后台看余量 |
| 只有一部分节点超时 | 正常现象 | 换一个节点，不用反复刷新订阅 |
| 晚上明显变慢 | 线路晚高峰拥堵 | 换一条线路；这是线路问题，换客户端没用 |
| 浏览器能用，某个软件不行 | 那个软件不走系统代理 | 在该软件里单独填代理地址，或用 TUN 模式 |
| 启动报端口被占用 | 同时开着两个代理客户端 | 关掉一个，或改端口 |

「昨天还能用」的问题，九成是三件事之一：订阅过期、线路被封、杀软更新后把内核删了。按这个顺序查，省时间。

别急着重装客户端。问题通常在订阅、规则或线路，重装只会让你把订阅再导一遍。先看日志。

用 v2rayN 的，网页版有三篇对着报错写的排查：[v2rayN 导入订阅失败怎么排查](https://www.jiediancha.com/blog/v2rayn-import-subscription-failed/)、[v2rayN 连不上的四层排查法](https://www.jiediancha.com/blog/v2rayn-cannot-connect-four-layers/)、[REALITY 节点导入成功却连不上](https://www.jiediancha.com/blog/v2rayn-imported-but-cannot-connect-reality-core/)。其余文章在[打不开时怎么自己判断（知识库）](https://www.jiediancha.com/blog/)。

## VPN 推荐：成品 VPN 和机场什么时候选哪个

VPN 推荐前先分清两样：成品 VPN 是装好就连的 App，机场卖订阅要自己配客户端。差别在出问题时你能不能自己查出原因。

这一节不点名任何成品 VPN 品牌。原因很直接：成品 VPN 能不能用，体现在客户端能不能连上，从外面没法用统一的方法核查。我核查不了的东西，不推荐。

什么时候选哪个：

| 你的情况 | 我的建议 |
| --- | --- |
| 只想手机上偶尔看看，不想碰任何设置 | 成品 VPN 能省事，但先买最短周期 |
| 手机、电脑、平板都要用 | 机场。一条订阅多台设备共用，成本低得多 |
| 在意出了问题能不能自己排查 | 机场。订阅、节点、规则各自能单独验证 |
| 要分流（国内直连、境外走代理） | 机场配 Clash 系客户端，规则开箱就有 |
| 会用 Linux，想独享一条线路 | 自建 |

用机场时，「订阅拉不到节点」和「节点全部不通」是两类故障，排查方向相反，你自己能分清。用成品 VPN 时，多数故障只表现为「连不上」，原因在客户端内部，你能拿到的信息少得多。

还有一个容易被忽略的风险差别：机场的风险是入口失联和停运，都有外部能看到的迹象；成品 VPN 的风险多在账号和计费层面，从公开渠道看不到。

成品 VPN 和机场在可核查性上的区别，网页版有一页专门讲：[VPN 与机场能不能从外部核查](https://www.jiediancha.com/vpn/)。

## 机场跑路怎么提前看出来：停运核查与入口核查

机场跑路前通常有四种外部能核对的前兆：入口换得变勤、关闭注册、支付渠道频换、长期超常年付折扣。见到两条就别续年付。

**入口更换频率突然变高。** 正常的防封轮换有节奏，几个月换一次域名。短期内换好几次、新入口活得一次比一次短，是运维撑不住的外部表现。

**停止新用户注册。** 注册入口关闭或长期报错。

**支付渠道频繁更换。** 收款方式短期内变了几次。

**力度异常的长期促销。** 远超行业常规的年付折扣，本质是把以后的现金流提前收回来。

看稳定，看的是入口的历史记录，不是宣传语：

- 节奏平缓：几个月一次域名轮换，属正常运维。
- 节奏突然加快：短期多次更换，值得警惕。
- 长期不变：可能是运维稳，也可能只是没被针对，两种都有，单凭这条下不了结论。

怎么用这条时间线判断稳定，见[稳定机场看变更记录不看宣传](https://www.jiediancha.com/stable/)。

**域名年限也能查。** 域名注册日期通过 RDAP 公开查询，任何人都能查。年限长证明不了可靠；但极新的域名配上激进的年付促销，这个组合要单独掂量，因为年付把风险全推到了你这边。注册日期也不等于开始运营的日期，域名可能是买来的二手域名。

从外面看不到的东西，我不推断：后台还发不发货、客服还回不回、余额能不能退。这些写不进记录。

我对付跑路风险的办法只有一条：**月付**。愿意让你按月验证的服务商，对自己的存续更有底气；你也最多损失一个月。

各家入口的变更时间线，网页版逐条记录在[机场入口变更记录](https://www.jiediancha.com/changes/)，跑路前兆的完整说明见[机场跑路的可核对前兆](https://www.jiediancha.com/paolu/)。

## 节点检测：延迟、超时和晚高峰三日自测

节点检测看延迟、丢包、抖动、带宽四项。同一节点不同时段的差异常大过不同节点之间的差异，所以要连续三天同一时段测。

### 四个指标各自怎么测

| 指标 | 怎么测 | 参考区间（通用经验值） | 常见误读 |
| --- | --- | --- | --- |
| 延迟 RTT（ms） | `ping <地址>`；HTTP 层用 `curl -o /dev/null -s -w "%{time_total}\n" <URL>` | 跨境优化线路 60–150；跨境普通线路 150–300；>300 明显影响交互 | 把一次 ping 当结论。要看连续多次的分布 |
| 丢包率（%） | `ping -n 100 <地址>`（Windows）/ `ping -c 100 <地址>`（macOS、Linux），看统计行的 loss | 0–1% 一般无感；1–3% 网页偶发卡顿；>5% 通话游戏基本不可用 | 丢掉的包不产生延迟数字，链路越烂平均延迟反而可能越好看 |
| 抖动（ms） | 同一批 ping 的最大值减最小值 | <20 稳定；20–50 通话偶有杂音；>50 明显断续 | 只盯平均延迟。平均 80ms 但在 40–400 之间跳，体验远差于稳定的 150ms |
| 下载带宽（Mbps） | 持续 10 秒以上的下载测速，看稳定段 | 1080p 要稳定 ≥5；4K 要 ≥25 | 拿峰值当结论。前两秒的冲高不算数 |

参考区间是通用经验值，不是哪家机场的测速结果。

**测之前先排除本地因素**，不然后面的数都不可信：关代理先测直连延迟，本地就丢包的话节点再好也没用；能插网线就插网线；关掉云盘同步和系统更新；确认没有两层代理叠在一起。

### Clash 里的「延迟」测的是什么

Clash 系客户端点「测延迟」，是通过这条节点向一个固定测试网址发一次请求，记录拿到响应头的耗时。它不测带宽，只测一次往返。

所以会出现这些看起来矛盾的情况：显示 80ms 但视频一直缓冲（延迟测试不测带宽）；同一节点两次差 200ms（单次采样）；换个客户端数字对不上（默认测试网址不同，跨客户端比没有意义）；所有节点一起变高（大概率是本地或测试网址那头的问题）。

这个数只拿来做一件事：同一时刻、同一客户端下，比哪条节点更快。延迟测得出来不等于那条线路对你要用的网站是通的，可用性要靠实际访问验证。

### 三日自测流程

每次测量做这几步：

0. 关代理，ping 国内一个大站 100 次，记下直连基线。基线异常就今天不测，先修本地网络。
1. 客户端里对候选节点各测一次延迟，不通的直接出局。
2. 对每条候选节点连续 ping 100 次，记平均延迟、最小–最大、丢包率。
3. 跑一次持续 10 秒以上的下载测速，记稳定段平均值。
4. 打开你日常真正要用的几个网站或应用，各用 30 秒。前三步全绿而这一步不行，以这一步为准。

三天后这样读：

| 三天的表现 | 结论 |
| --- | --- |
| 三天都稳，波动 <20% | 这个时段可用，固定下来 |
| 两天好一天差 | 偶发，留作备用 |
| 三天逐日变差 | 稳定劣化，考虑换线路 |
| 每天同一时段差、其它时段好 | 时段性拥塞，不是坏了 |
| 数字都好但第 4 步一直不行 | 不是性能问题，回去看「Clash 机场」一节的报错表 |

### 记录模板

一天一行，每条候选节点一份。测完不记等于没测，三天后你不会记得周一晚上那条线是 90ms 还是 190ms。

| 日期 | 时段 | 直连基线 | 节点 | 连通 | 平均延迟 | 最小–最大 | 丢包率 | 下载带宽 | 实际用着顺不顺 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 第 1 天 | 21:00 |  |  |  |  |  |  |  |  |  |
| 第 2 天 | 21:00 |  |  |  |  |  |  |  |  |  |
| 第 3 天 | 21:00 |  |  |  |  |  |  |  |  |  |

节点用你自己的固定叫法（如「香港-A」），别用会随订阅更新变化的序号。时段精确到小时，三天保持一致。备注里记下当晚有没有在下载大文件、换没换过网络。

### 节点全红、部分红时先查什么

**全部节点超时**：几乎不可能是所有服务器同时挂掉。一定是某个共同的上游坏了，按顺序查：本地网络 → 系统时间（偏差大会导致 TLS 握手失败）→ 套餐是否到期、流量是否用完 → 订阅链接是否失效 → 换一个客户端导入同一份订阅试试。

**部分节点超时**：正常状态。红的集中在同一地区，是那条线路的问题；红的都是高倍率组，可能不在你的套餐内；只在某个时段红，是拥塞。只要你常用的那几条稳，不必追求全绿。

**能连上但打不开网页**：传输层通了，应用层没通。看连接日志确认那条请求走的是哪条规则；换节点侧解析 DNS 再试；换一条不同地区的节点试同一个网址，换了就好说明是出口 IP 被那个网站限制了。

## 常见问题

**梯子和 VPN 是一回事吗？**
不完全是。梯子是统称，成品 VPN 是其中一种。中文语境里说「买梯子」，多数时候指买机场订阅。

**新手第一次买机场，买月付还是年付？**
月付。第一个月是用来验证的，晚高峰跑三天没问题再考虑长期套餐。

**为什么这个仓库不放测速数字？**
我没有能公开复核的测速记录。别人的截图不可移植，你的城市、运营商、时段都不同。不放比放一个编的强。

**为什么不给机场的「最新地址」？**
记录是信息，导航是分发，两件事性质不同（[为什么只记录、不分发](https://www.jiediancha.com/about/)）。这个仓库和网页版只写「某个入口在某天之后不再被观察到可用」，不提供可点击的访问入口。

**推荐表多久更新一次？**
不定期。表头写了核对日期，以那个日期为准。日期很旧的话，价格以官网结算页为准。

**订阅链接会过期吗？**
会。套餐到期或你在后台重置订阅后，原链接就失效了，要回后台重新复制。

**一个订阅能在几台设备上用？**
看套餐的设备数限制，低档常限 2–3 台。超了会被限速或踢下线，症状像「被墙了」。

**机场打不开就是跑路了吗？**
不是。被墙、限流、临时故障、域名到期都会打不开。要确认停运，得有官方公告或公开存档这类依据。见「翻墙打不开先分层」一节。

**这个仓库收钱改排名吗？**
推荐表的顺序是我定的，含合作关系，已在表头写明。状态记录不打分、不排名、不接受付费修改。发现记录有错，走[信息更正入口](https://www.jiediancha.com/correct/)；合作与其他反馈走[反馈与合作](https://www.jiediancha.com/contact/)。
